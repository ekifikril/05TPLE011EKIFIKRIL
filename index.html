Mata Kuliah Pemrograman Web 1

Mata kuliah Pemrograman Web 1 merupakan mata kuliah dasar yang membahas konsep dan prinsip pengembangan website statis dengan menggunakan bahasa pemrograman HTML, CSS, dan JavaScript. Mata kuliah ini bertujuan untuk memberikan pemahaman kepada mahasiswa mengenai struktur halaman web, pengelolaan tampilan antarmuka, serta penerapan interaksi dasar pada website, sehingga mahasiswa mampu merancang dan membangun website yang terstruktur, responsif, dan sesuai dengan standar pengembangan web.

Visi

Membekali mahasiswa dengan kemampuan dasar pengembangan website yang terstruktur, rapi, dan responsif.

Misi

  • Memahami konsep dasar web
  • Mampu membuat website statis
  • Mengenal HTML, CSS, dan JavaScript
